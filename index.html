📋 분기 평가서 탭

  1. 수업반 이름을 입력하고 교재를 선택하면 평가 항목이 자동으로 나타납니다.
  2. 좌측 "+ 학생 추가"로 학생을 추가한 뒤, 이름과 항목별 상/중/하를 선택하세요.
  3. 좌측 목록의 초록 체크(✓)는 입력 완료, 빨간 느낌표(!)는 이름은 있지만 항목이 비어있는 상태입니다.
  4. 우측 미리보기에서 완성 문장을 다운로드 전에 확인할 수 있습니다.
  5. 모든 학생 입력이 끝나면 하단 "전체 리포트 ZIP 다운로드"를 클릭하세요.

📢 학습 진도 안내 양식 탭

  1. 교재를 선택하면 차시 목록이 나타납니다. 이번 달 진행한 차시를 체크하세요.
  2. "학습목표 ▾"를 누르면 해당 차시의 학습목표를 펼쳐볼 수 있습니다.
  3. 체크한 차시들의 안내문구가 자동으로 이어붙여져 "반 공통 학습내용 미리보기"에 표시됩니다.
  4. 학생 이름과 개별 한줄 메모를 입력한 뒤 ZIP 다운로드를 누르면, 학생별로 공통 문구 + 개별 메모가 담긴 파일이 생성됩니다.
💡 두 탭 모두 강사가 입력한 학생 이름·평가·메모는 서버에 저장되지 않고, 다운로드 순간 브라우저 안에서만 워드 파일로 만들어집니다.
